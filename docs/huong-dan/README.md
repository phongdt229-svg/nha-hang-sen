# Hướng dẫn nhân viên

Mỗi vai trò 1–2 trang, in ra dán tại quầy/bếp. Cùng nội dung này hiện trong app: nút **Hướng dẫn** trên POS, màn hình bếp và tablet — sửa file ở đây là app cập nhật theo ở bản build sau.

| Vai trò | Hướng dẫn |
|---|---|
| Thu ngân | [thu-ngan.md](thu-ngan.md) |
| Phục vụ / lễ tân | [phuc-vu.md](phuc-vu.md) |
| Bếp | [bep.md](bep.md) |
| Quản lý ca | [quan-ly.md](quan-ly.md) |
| Kế toán, chủ quán | [ke-toan-chu-quan.md](ke-toan-chu-quan.md) |
| Khách (tablet tại bàn) | [khach-hang.md](khach-hang.md) |

**Nhân viên mới:** [chương trình đào tạo](dao-tao.md) — lộ trình buổi đầu, bài tập theo vai trò (đánh dấu được trong app), tình huống sự cố, câu hỏi kiểm tra, tiêu chí đạt.

Tập huấn / kiểm tra trước giờ mở bán: [chạy thử toàn bộ luồng](chay-thu.md) (trên POS có bản theo dõi trực tiếp).

Sự cố: [sổ tay xử lý sự cố](../van-hanh/runbook.md).
